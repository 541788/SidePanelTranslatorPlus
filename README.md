# Side Panel Translator Plus

在浏览器侧边栏里完成**翻译**、**朗读**、**划词翻译**、**单词取词**，并把生词**同步到墨墨背单词**。

本项目基于开源扩展 **Side Panel Translator 0.3.0** 构建，在其后台翻译管线之上重做了侧边栏界面，并新增朗读、划词翻译、单词即时释义和生词本/墨墨云词本联动。

## 功能

### 翻译

- 侧边栏多服务并行翻译，一次看到多个引擎的结果，方便对照。
- 译文框可直接编辑，改完再复制。
- 目标语言 185 种可选。

### 朗读

- 一键朗读原文，按文本语言自动匹配系统语音。
- 每条译文单独朗读。
- 可调语速、指定语音，支持翻译完成后自动朗读。

### 划词翻译（网页内）

- 选中网页文字 → 选区旁出现「翻译」气泡 → 点击即译。
- 也可设为「选中即自动翻译」。
- 结果卡片支持朗读原文/译文、复制译文、在侧边栏打开。
- 右键菜单「在侧边栏翻译"…"」作为兜底路径，不受页面脚本限制。

### 单词即时释义

在侧边栏的原文输入框或任意一条译文里选中**单个单词**，紧贴选区弹出小卡片显示释义，卡片上可直接朗读或加入生词本。

- 选整句、选多个词不会弹，避免干扰。
- 可在设置里关闭。

### 生词本与墨墨联动

这是本项目相对原版最主要的增量功能。

**收集单词的三种方式**

- 原文取词：点输入框左下角 `+`，原文变成可点单词，点选后批量加入。
- 划词卡片取词：网页划词翻译卡片下方会列出选区内的单词，点一下加入、再点移除。
- 单词弹窗取词：选中单个单词后，在弹出卡片里一键加入。

**生词本**

- 每个单词四个操作：朗读、翻译（就地展开释义）、单独加入墨墨、移除。
- 复制全部：每行一词，可直接粘贴到墨墨。
- 同步到墨墨：整本写入指定云词本。
- 清空需二次确认。

**墨墨云词本管理**

直接在本扩展里管理墨墨云词本，不用切到手机 App：

- 新建词本，创建后自动设为当前目标。
- 重命名，改动实时写回墨墨云端。
- 删除，先弹确认条，点「确认删除」才执行。
- 点词本名即可切换当前同步目标。

**去重规则**

同步前会读取云端词本现有内容，逐词比对（不区分大小写），只追加新增的词。重复同步不会产生重复条目，提示会明确说明「里已有 xxx」。所有写入走串行队列，避免同时点多个词时后写覆盖先写。

**一个边界**

同步写入的是墨墨的**云词本**（文本模式，每行一词），不是学习队列。云词本不会自动进入当天的背诵计划，需要在墨墨 App 里把该词本加入学习。好处是不受墨墨词库是否收录该词的限制，专业术语（如 `conformal`、`isotropic`）也能存进去。

## 安装（Edge / Chrome 开发者模式）

1. 下载或克隆本仓库到本地。
2. 打开 `edge://extensions/`（Chrome 为 `chrome://extensions/`）。
3. 打开右下角「开发人员模式」。
4. 点「加载解压缩的扩展」，选择本仓库根目录。
5. 点工具栏上的扩展图标，侧边栏即打开。

## 配置

### 翻译服务

点侧边栏顶部的「翻译服务与 API 设置」打开设置页，在「服务」里启用并填写你自己的 Key。可用的服务包括 Google、Microsoft、DeepL、腾讯、豆包、OpenAI、DeepSeek、Moonshot、xAI 等。

**本仓库不包含任何 API Key**，所有服务默认关闭，需自行配置。

### 墨墨背单词

1. 墨墨 App → 我的 → 更多设置 → 实验功能 → 开放 API，复制 Token。
2. 侧边栏 → 生词本 → 「墨墨云词本」区粘贴 Token → 点「保存 Token」。
3. 点选目标云词本，或点「新建词本」自建一个。

Token 只保存在本机浏览器的 `chrome.storage.local`，不会上传到任何服务器，也不会写入本仓库文件。

## 权限说明

| 权限 | 用途 |
|------|------|
| `storage` / `unlimitedStorage` | 保存设置、生词本、翻译缓存 |
| `sidePanel` | 提供侧边栏界面 |
| `contextMenus` | 右键菜单「在侧边栏翻译」 |
| `<all_urls>` 内容脚本 | 在网页中提供划词翻译浮层 |
| 各翻译服务域名 | 调用对应翻译 API |
| `open.maimemo.com` | 读写墨墨云词本 |

## 已知限制

- 划词浮层运行在网页里，严格 CSP 或 Canvas 渲染的站点可能不响应，此时改用右键菜单或侧边栏粘贴。
- 云词本不进入学习队列，需在墨墨 App 里手动加入。
- 单词释义走实时翻译接口，首次结果通常需要 1–5 秒，不做本地缓存。
- 扩展 ID 与本地路径绑定，移动文件夹后需在扩展管理页重新加载，浏览器存储不会自动继承。
